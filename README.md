Create a modern, premium, highly responsive personal portfolio website for Innocent, a Data Analyst building a career at the intersection of Data Analytics, Business Intelligence, Python, SQL, Excel, Power BI, Artificial Intelligence, and Intelligent Automation.

The website must feel like a serious professional portfolio designed to impress recruiters, hiring managers, clients, and potential employers.

Use the attached reference screenshot as inspiration for the overall visual hierarchy and clean portfolio experience, but DO NOT copy its identity, text, branding, or exact design. Create an original interface with a stronger Data/AI identity.

1. CORE PROFESSIONAL POSITIONING

The website must immediately communicate:

Primary identity:
Data Analyst

Professional direction:
Data Analytics • Business Intelligence • AI • Intelligent Automation

Do NOT position Innocent as a Front-End Developer, Full-Stack Developer, or Software Engineer.

The website should communicate that Innocent uses technology as a tool to solve business and data problems.

Core message:

Turning complex data into clear, actionable insights.

The design should make this positioning obvious within the first few seconds of visiting the website.

2. DESIGN DIRECTION

Create a visual identity that is:

Minimal

Premium

Professional

Intelligent

Modern

Clean

Data-focused

Recruiter-friendly

Highly readable

Elegant without being flashy

Avoid generic developer portfolio aesthetics.

Avoid excessive gradients.

Avoid excessive glassmorphism.

Avoid huge animated objects.

Avoid unnecessary 3D effects.

Avoid a template-looking website.

Use strong typography, whitespace, subtle motion, excellent spacing, and carefully designed visual hierarchy.

The website should feel like a professional Data Intelligence portfolio, not a coding experiment.

3. NAVIGATION

Create a clean sticky navigation bar.

Navigation:

Home

About

View Resume

The navigation must become a mobile-friendly hamburger menu on smaller screens.

The navbar should remain clean and unobtrusive while scrolling.
